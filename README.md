# LeetCode Solutions

My solutions to LeetCode problems, one folder per problem. Each folder has the problem statement and my solution file.

Solutions are synced from LeetCode with [LeetHub](https://github.com/QasimWani/LeetHub), so each commit is created automatically when a submission is accepted.

## Layout

```
leetcode-solutions/
└── <number>-<problem-slug>/
    ├── README.md          # Problem statement, examples and link to LeetCode
    └── <number>-<problem-slug>.<ext>   # My solution
```

## Notes

- Folders are named by problem number and slug, so they sort in LeetCode order.
- The `README.md` in each folder is the problem statement copied from LeetCode.
- The commit messages record the runtime and memory results LeetCode reported, for example `Time: 8 ms (7.49%), Space: 19.5 MB (79.38%)`.
